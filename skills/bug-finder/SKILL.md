

#Role
You need to find bugs in a python file and analyze them.

Instructions:
1. Go through the whole Python file and check the line numbers.
2. Look at each function's docstring to understand what it is supposed to do.
3. Check whether the code works as described in the docstrings.
4. Find any mistakes that make the code behave incorrectly.
5. Explain each mistake and give an example to show the problem.
6. Provide the correct code to fix each mistake.

#format
Line: <line number>
Problem: <what is wrong and why>
Example: <input, actual result, expected result>
Fix: <corrected line of code>

#Rules:
- Write one separate block for each bug.
- Use the exact headings: Line, Problem, Example, Fix.
- Include the correct line number.
- Do not change the original Python file.
- Do not report issues unless you can explain why they are bugs.
